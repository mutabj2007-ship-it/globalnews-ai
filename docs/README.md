# GlobalNews AI — Documentation

This folder holds project documentation that isn't code: architecture
decisions, SRS references, API contracts, and onboarding notes.

## Structure (to be expanded in later sprints)

- `architecture.md` — high-level system architecture (added when backend
  services and data flow are defined)
- `api/` — API contract docs (added alongside backend endpoints)
- `adr/` — Architecture Decision Records

## Sprint 1 status

Only the project foundation exists at this stage. No application features,
authentication, AI integration, news retrieval, or dashboards have been
implemented yet. See the root `README.md` for setup instructions.
