Alpha public gates: unchanged

## Product Owner defect

The generic `AlphaRetainedReportingDock` proved retained reporting exists but violated the
accepted specialist information architecture. It created a fifth blocking region, obscured
maps/substrates, treated keyword-matched reporting as domain data, and left the native
structured observation surfaces empty.

That overlay is removed on this branch. Retained reporting remains available through the
admin Alpha review contract only until a domain admits it.

## Non-negotiable rendering rule

Articles are evidence, not the specialist product object.

No dashboard may derive a primary domain state from a title/summary keyword match. A domain
surface is fed only by its accepted structured observation contract. Retained news can appear
only in a native evidence/provenance surface after the domain contract says it may.

No new permanent region is permitted. Existing Claude Design geometry remains authoritative
on desktop and compact/phone.

A PASS requires all of the following:
- no AlphaRetainedReportingDock import or mount on any specialist dashboard;
- no keyword-to-domain primary projection;
- every visible specialist datum has a native observation record and provenance;
- maps draw only structured geographies from the domain observation;
- empty/coverage-gap states remain truthful where a domain has no admitted observation;
- EN/PL preserved;
- desktop and phone/compact validated;
- opening a dashboard performs no AI call and no external provider call;
- Production HOLD preserved;
- Product Owner can inspect retained candidate evidence in Admin without publishing it.
